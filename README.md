# lidoshop.ru — Редизайн и UX-прототип (HostCMS Ready)

Интерактивный прототип нового дизайна интернет-магазина дизайнерской одежды больших размеров **LidO** (размеры 46–60, основатель Ольга Чернухина).

## Что реализовано
- **Современная редакционная эстетика**: палитра Alabaster / Travertine / Obsidian / Burgundy Velvet, шрифтовая пара *Cormorant Garamond* + *Manrope*, плавные микро-анимации (`IntersectionObserver`, hover-эффекты, slide-over корзина).
- **Переосмысленная структура каталога**: единая логичная навигация с фильтрацией по категориям и фильтром скидок до −40%.
- **Конструктор «Готовые образы / Капсулы» (Total Look)**: интерактивный подбор комплекта со скидкой −10% и добавлением всего образа в корзину в 1 клик.
- **Калькулятор размера 46–60 (Smart Fit)**: расчёт по ОГ / ОТ / ОБ и быстрая передача мерок стилисту в Telegram.
- **Корзина с прогресс-баром подарка**: визуальный трекер до 25 000 ₽ (авторское украшение ручной работы в подарок) и акцент на 14-дневной примерке СДЭК.

Подробности по переносу на CMS см. в [HOSTCMS_INTEGRATION.md](./HOSTCMS_INTEGRATION.md).
